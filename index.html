About

Orvel Studio is a one-person studio founded in 2026 in South Korea. Each game starts from a single idea and is kept small enough to finish in one sitting.

We build with Godot and an AI-assisted pipeline for art, code and sound, which lets a studio of one ship games that would normally need a team. Everything is self-published on Steam.
